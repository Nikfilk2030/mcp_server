# Публикация и удаление сервера

Обязательные инструменты проверяются локально. Для демонстрации через удалённую Алису нужен внешний HTTPS-адрес. Личный платёжный аккаунт не является требованием задания: преподаватель предоставляет учебный Linux-хост либо объявляет другой способ размещения до начала работы.

## Что должно быть подготовлено

- Отдельный учебный Linux-хост с Docker Engine и Compose v2.
- SSH-доступ и имя хоста с A-записью на его публичный IPv4.
- Входящие TCP 80 и 443 для HTTPS и выдачи сертификата. SSH ограничивается согласованными адресами администратора.
- Порты 80 и 443 свободны: этот Compose рассчитан на один сервер на хосте. Не запускайте его поверх чужих сервисов.

Docker и Caddy являются готовой инфраструктурой. Студенту не нужно настраивать облачный аккаунт, писать OpenTofu или разбираться в выдаче TLS-сертификата.

## Запуск на учебном хосте

В каталоге своей копии репозитория на хосте:

```bash
cp .env.example .env
```

В `.env` замените `your-host.example` на выданное DNS-имя, без `https://`, порта и пути. Адрес из примера не рабочий.

```bash
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose logs --tail=50 app caddy
```

После первого запуска подождите выдачи HTTPS-сертификата. Caddy использует внешнюю службу сертификации; публичное DNS-имя и открытые порты обязательны. Само приложение не публикует порт 8000 наружу. В шаблоне нет авторизации: отправляйте только учебные данные.

На своём компьютере проверьте адрес:

```bash
python client.py --url https://your-host.example/mcp
python client.py --url https://your-host.example/mcp --tool echo --arguments '{"text":"hello"}'
```

Затем подключите этот же URL к [Алисе](alice.md).

## Обновление

Доставьте новую версию своего кода на хост и повторите `docker compose up -d --build`. Для конкурсных вспомогательных модулей и статических данных дополните явный список `COPY` в `Dockerfile`; не копируйте в образ `.env`, тестовые артефакты или ключи. Новые зависимости зафиксируйте в `requirements.txt`.

Приложение запускается непривилегированным пользователем с файловой системой только для чтения. Медиа формируйте в памяти. Если необходим временный файл, доступен ограниченный `/tmp`; не сохраняйте историю запросов.

## Завершение

Для выделенного под эту лабораторную экземпляра:

```bash
docker compose down --volumes --remove-orphans
```

Команда удаляет контейнеры и тома этого Compose-проекта, включая TLS-сертификаты. Не выполняйте её для общего проекта преподавателя.

**Это не удаляет облачную машину, её диск или публичный IP.** Удалите выделенные ресурсы через согласованный облачный способ либо передайте запрос администратору учебного размещения и получите подтверждение. Простая остановка машины не прекращает оплату всех ресурсов.

Перезапуск контейнера после сбоя настроен. Автоматический запуск остановленной прерываемой ВМ этим шаблоном не настраивается. Время записи согласуйте так, чтобы машина работала во время демонстрации.
