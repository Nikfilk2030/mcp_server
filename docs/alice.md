# Подключение к Алисе

Алиса — клиент для проверки пользовательских сценариев. Не используйте её для написания кода, отладки реализации и подготовки отчёта.

## Перед подключением

1. Выполните `python -m pytest`: обязательные проверки должны пройти.
2. [Опубликуйте сервер](deployment.md) и проверьте HTTPS.
3. Вызовите внешний сервер через `client.py` с вашего компьютера:

```bash
python client.py --url https://your-host.example/mcp
python client.py --url https://your-host.example/mcp --tool echo --arguments '{"text":"hello"}'
```

## Параметры соединения

| Параметр | Значение |
| --- | --- |
| URL | Полный HTTPS-адрес, заканчивающийся на `/mcp` |
| Транспорт | Streamable HTTP |
| Авторизация | Нет в учебном шаблоне |
| Инструменты | `echo`, `inspect_unicode`, `render_identicon` и ваши дополнительные |

### Учебный harness — заполняется преподавателем

- Ссылка на Алису: ____________________
- Версия harness: ____________________
- Инструкция или конфигурация добавления MCP: ____________________

Место оставлено пустым намеренно. До выдачи задания преподаватель добавит точный способ подключения для используемой версии Алисы.

После добавления адреса убедитесь, что Алиса обнаружила инструменты. Локальный адрес `127.0.0.1` недоступен удалённому harness; ему нужен внешний endpoint. Страница `/healthz` проверяет процесс, но не является адресом для подключения MCP.

## Сценарии демонстрации

**Unicode:** «Разбери строку Aа: какие в ней символы и почему они могут выглядеть похоже?» Вторая буква в примере — кириллическая `а`.

**Изображение:** «Сделай геометрический аватар для ника student42».

**Свободная тема:** ваш обычный пользовательский запрос без указания имени инструмента.

Покажите вызванный инструмент, аргументы и результат. Точный текст ответа Алисы не оценивается. Если она не выбрала инструмент, можно повторить запрос или явно попросить воспользоваться подключённым сервером; не скрывайте это в записи. Одного текстового заявления «я вызвала инструмент» недостаточно: нужен журнал вызова или соответствующее представление harness.

## Если что-то не работает

| Симптом | Самостоятельная проверка |
| --- | --- |
| Нет соединения | URL, работа контейнеров, DNS, порты 80/443, `client.py` |
| Нет нужного инструмента | Регистрация, перезапуск процесса, повторное подключение MCP |
| Ошибка аргументов | Схема из `client.py`, контракт и открытые тесты |
| Картинка не отображается | Прямой вызов через `client.py --save-dir artifacts`, затем проверка возможностей harness у преподавателя |

Не просите Алису диагностировать или исправлять код сервера.
