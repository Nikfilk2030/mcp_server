# Конкурс свободных MCP-серверов

Конкурс добровольный и не уменьшает оценку за обязательное задание. Допуск: все обязательные тесты проходят, правила самостоятельной работы соблюдены, сервер воспроизводимо запускается.

## Задача

Придумайте способность Алисы, которой помогает внешний инструмент. Реализуйте её в `custom_tools.py`; вспомогательные модули и небольшие статические данные можно добавить в репозиторий.

Один хороший инструмент может быть полноценной конкурсной работой. Количество функций, строк кода и используемых MCP-возможностей само по себе не даёт преимущества.

## Ограничения

- Python; без LLM при разработке и внутри сервера.
- Без БД, истории пользователей и внешних сетевых запросов из инструментов.
- Входные данные поступают аргументами либо входят в проект как статические материалы.
- Ограничьте размеры входов, выходов и объём вычислений; опишите ограничения.
- Не выполняйте произвольные команды, не используйте `eval` для пользовательского ввода, не принимайте произвольные пути к файлам.
- Добавьте собственные тесты, включая хотя бы один некорректный ввод.
- Не ломайте обязательные инструменты и штатный способ запуска.
- Изображения, звук, ресурсы и prompts допустимы. Проверьте поддержку выбранного вида результата в учебной Алисе до записи.

## Идеи для вдохновения

| Направление | Пример способности |
| --- | --- |
| Геометрия | Построить бумажную развёртку или мозаику |
| Музыка | Синтезировать интервал и показать частоты |
| Алгоритмы | Нарисовать лабиринт и путь через него |
| Цвет | Проверить контраст палитры и показать образцы |
| Данные | Из короткой последовательности построить наглядную диаграмму |

Собственная тема приветствуется; перечисленные идеи не являются дополнительными обязательными задачами.

## Представление работы

В `SUBMISSION.md` укажите: пользовательскую задачу, список инструментов, пример запроса к Алисе, ограничения, инструкцию запуска своих тестов. В демонстрации покажите результат, который получен через реальный MCP-вызов.

На конкурс подаётся фиксированный commit SHA. Организаторы используют одинаковые настройки Алисы и одинаковые ресурсы размещения. Если генератор использует случайность, предусмотрите `seed` для воспроизводимой демонстрации.

## Номинации

- **Самая полезная способность**: понятная задача и убедительная польза результата.
- **Самая неожиданная идея**: оригинальность применения.
- **Лучшее исполнение**: ясные интерфейсы, корректность, тесты, обработка ошибок и воспроизводимость.

Жюри рассматривает реализацию и запись. Обаяние ответа Алисы, число инструментов и мощность личного компьютера не оцениваются. Зрительское голосование, если проводится, даёт отдельную награду. Даты, состав жюри и призы объявляются преподавателем до начала конкурса.
