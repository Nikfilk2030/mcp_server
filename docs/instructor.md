# Памятка преподавателю

Это публичная организационная памятка. Эталонная реализация, ответы на вопросы защиты и закрытые тесты должны храниться отдельно от студенческого репозитория и его Git-истории.

## До выдачи

- [ ] Утвердить сроки, способ сдачи и правила самостоятельности курса.
- [ ] Зафиксировать ссылку/версию harness Алисы и добавить его точную инструкцию подключения в `docs/alice.md`.
- [ ] Проверить отображение изображений и доступность журнала вызовов в harness.
- [ ] Выдать учебное размещение или объявить альтернативу без обязательной личной банковской карты.
- [ ] Проверить шаблон на чистом Python 3.12.12 и показать вызов `echo`.
- [ ] Включить GitHub repository setting **Template repository**, если используется выдача через **Use this template**.
- [ ] Убедиться, что `RUN_ASSIGNMENT_TESTS` выключен в исходном шаблоне: полный набор намеренно не проходит без реализации.
- [ ] Провести пилот задания на одном участнике целевого уровня.
- [ ] До начала конкурса объявить даты, номинации, жюри и возможные награды.

В этом репозитории подготовлены открытые тесты. Закрытый проверяющий комплект и изолированная инфраструктура массовой проверки отдельно не развёрнуты.

## Автоматическая проверка

CI **Template checks** подтверждает только работоспособность каркаса и контейнера. CI **Assignment checks** запускает полный набор вручную либо автоматически при repository variable `RUN_ASSIGNMENT_TESTS=true`. Workflow с ручным запуском должен присутствовать в default branch студенческого репозитория, чтобы GitHub показал кнопку запуска.

Для оценки используйте неизменённую копию тестов преподавателя. Не доверяйте зелёному workflow студента как единственному доказательству: его проверки могли быть изменены. Запускайте присланный код в отдельном изолированном окружении без секретов, внешней сети и доступа к рабочим каталогам организаторов. Сеть loopback внутри окружения нужна для MCP-клиента и сервера.

Зависимости устанавливаются из согласованного набора до отключения внешней сети. Ограничьте память, CPU, количество процессов и время запуска. Репозиторий содержит ограничения учебного контейнера, но Docker сам по себе не является готовой системой безопасного исполнения произвольных недоверенных работ; для массовой проверки используйте инфраструктуру курса.

Закрытые случаи могут варьировать строки, формы нормализации, seed, размеры и порядок запросов. Они не вводят новых требований. Не сравнивайте байты PNG, точные тексты ошибок или сериализацию JSON Schema. Весь обязательный контракт опубликован в `docs/contracts.md`.

## Защита: 5–7 минут

Попросите объяснить один структурированный ответ и один image-блок, найти соответствующий раздел документации, показать ошибочный ввод и восстановление. Для маленькой самостоятельной правки подойдут изменение описания инструмента или добавление дополнительного поля результата без нарушения обязательных полей.

Сначала разберите объяснение студента; сходство решения со стандартным примером документации не является само по себе нарушением. Автоматические AI-детекторы не используйте.

## Демонстрация и конкурс

Оценивайте реальные MCP-вызовы, а не уверенность формулировок Алисы. Повторные запросы допустимы. Технические сбои harness разбираются отдельно от корректности реализации.

Фиксируйте commit SHA конкурсных работ и одинаковые настройки модели, набор подключённых плагинов и ресурсы размещения. Отключайте посторонние инструменты, которые могут выполнить ту же задачу вместо студенческого MCP. Обязательные тесты — допуск в конкурс, а награды отделены от 100 баллов лабораторной.

После демонстраций проверьте удаление облачных ресурсов. Участники не должны оплачивать публичные endpoint до окончания проверки кода.
