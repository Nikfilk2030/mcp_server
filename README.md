# ДЗ 5. В какой аудитории встречается клуб?

Представьте, что у вас спрашивают: «В какой аудитории встречается клуб «Орбита»?» Источник ответа у вас уже есть: небольшое вымышленное расписание. Ваша задача: дать приложению способ прочитать его, а не заставить модель запомнить номера аудиторий. Расписание доступно только для чтения: менять встречи, бронировать комнаты и хранить данные студентов не нужно

MCP (Model Context Protocol) позволяет приложению узнать, какие инструменты предлагает сервер, и вызвать нужный инструмент с аргументами. LLM-хост в этом задании означает приложение, в котором модель может сама выбрать и вызвать подключённый инструмент. Начните с [инструкции к заготовке](starter/README.md)

## 6 баллов: найти аудиторию из терминала

- Реализуйте один инструмент поиска аудитории клуба. Используйте `club_id` и файл `schedule.json` из шаблона
- Проверьте два запроса: для известной встречи получите аудиторию из файла, для отсутствующей получите понятное «не найдено» без выдуманного номера
- Запустите MCP-сервер в Docker на виртуальной машине (ВМ). Из терминала ВМ проверьте его через `curl`: запросите список инструментов (`tools/list`), затем вызовите ваш инструмент (`tools/call`). Простого ответа «сервер работает» недостаточно
- Сохраните команды сборки и запуска, вывод со списком запущенных контейнеров и фактический обмен через `curl` для обоих запросов. Открывать сервер в интернет не требуется

## 8 баллов: показать свой MCP в LLM-хосте

В дополнение к уровню на 6 баллов подключите любой свой MCP-сервер к LLM-хосту. Придумайте собственный инструмент или содержательно расширьте базовый: например, по дню и времени найдите ближайшую встречу. Писать второй сервер не нужно. В README укажите, кому нужен ваш инструмент, параметры и пример результата

Задайте обычный вопрос, не называя инструмент. Сохраните один диалог, в котором видны вопрос, выбранный моделью инструмент, аргументы, результат вызова и итоговый ответ. Приложите название хоста и настройки подключения без секретов. Ручной вызов через `curl` не заменяет этот диалог

## 10 баллов: проверить поведение на десяти запросах

В дополнение к уровню на 8 баллов проведите [мини-проверку по инструкции](assignment/EVAL.md) на том же инструменте и заполните [таблицу из десяти строк](assignment/eval.csv). Мы оцениваем воспроизводимость проверки, а не число удачных ответов модели
