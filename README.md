# ДЗ 5. Свой инструмент для ассистента

Напишите инструмент, который находит аудиторию клуба по его идентификатору. Сначала вы вызовете его из терминала, затем запустите на виртуальной машине (ВМ) и зададите тот же вопрос ассистенту. Для всех 10 баллов достаточно одного инструмента

[Начать практикум](starter/README.md) · [Шаблон отчета](report.md) · [Как сдать](#сдача)

## За что ставятся баллы

Оценка равна старшему уровню, который вы подтвердили вместе со всеми предыдущими

| Баллы | Что сделать | Что показать в отчете |
|---|---|---|
| **4** | Запустить готовый сервер на localhost и вызвать `ping` | Четыре самостоятельно составленные команды `curl` и ответы сервера, включая пустой HTTP 202 и `pong`. Одной фразой поясните по `inputSchema`, как выбрали аргументы |
| **6** | Реализовать и зарегистрировать `lookup_club_room` | Код в `starter/`, результат тестов и локальный `tools/list` с новым инструментом. Вызов для `orbit` возвращает `Б-204`, для `ORBIT` возвращает `Клуб не найден`, оба без ошибки инструмента |
| **8** | Собрать тот же сервер в Docker и запустить на учебной ВМ. Подойдет ВМ из ДЗ № 4 | Ваш Dockerfile, команды сборки и запуска. В одном сеансе на ВМ покажите `docker ps`, список инструментов и вызов поиска с результатом |
| **10** | Подключить сервер на ВМ к ассистенту с поддержкой MCP. Спросить, например: «Где встречается клуб с идентификатором orbit?» | Название клиента и один реальный диалог: вопрос без имени функции, раскрытый вызов с именем инструмента, аргументами и результатом, затем ответ ассистента |

Например, работающий поиск на ноутбуке без запуска на ВМ дает 6. Если ВМ показана, но в чате виден только номер аудитории, это 8: по одному ответу нельзя отличить вызов инструмента от догадки. Публичный URL для 10 не нужен

## Конкурс плагинов

Лучшим плагинам мы щедро раздадим бонусные баллы

Чтобы участвовать, добавьте в `custom/` свой MCP-сервер. В `custom/README.md` напишите, кому он нужен и как его запустить. Покажите один вопрос и фактический вызов с результатом. При сравнении важны польза задачи, уместность инструмента и рабочая демонстрация, а не число методов. Без `custom/` можно получить все 10
