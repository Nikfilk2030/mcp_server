# ДЗ 5. Свой инструмент для ассистента

**Дедлайн:** TODO

Выберите оценку: каждый следующий уровень включает предыдущие. На 4 вы вызываете готовый инструмент через MCP на localhost. На 6 вы сами пишете инструмент, регистрируете его в MCP-сервере и собираете контейнер. На 8 вашим инструментом пользуется ассистент, а на 10 вы проверяете, насколько хорошо он это делает

## 4 балла: вызвать инструмент на localhost

1. Склонируйте репозиторий и [запустите MCP-сервер](starter/README.md) на своём компьютере. Для этого уровня не нужны Docker, ВМ и ассистент
2. Оставьте сервер работать. Из второго терминала начните обмен с `http://127.0.0.1:8000/mcp` через `curl`, затем запросите список инструментов методом `tools/list`
3. Найдите в ответе инструмент `ping`, посмотрите его `inputSchema` и самостоятельно составьте для него запрос `tools/call`. Проверьте, что сервер вернул `pong` в результате вызова

Приложите команды `curl` для списка и вызова вместе с фактическими ответами. Одной фразой поясните, какой из запросов описывает доступные инструменты, а какой выполняет инструмент. Один скриншот с `pong` без запроса не засчитывается

## 6 баллов: написать и развернуть MCP-инструмент

В [заготовке](starter/README.md) даны сервер с одним зарегистрированным инструментом `ping`, вымышленное расписание клубов и тесты. Ваша работа:

1. Реализуйте `lookup_club_room(club_id)` в `starter/tools.py`. Для точного идентификатора верните аудиторию из `schedule.json`, для неизвестного верните `Клуб не найден`. Проверьте тестами
2. Зарегистрируйте инструмент в `starter/server.py`. Проверьте, что в `tools/list` теперь есть не только `ping`, но и ваш инструмент
3. Скопируйте [Dockerfile.example](starter/Dockerfile.example) в `starter/Dockerfile` и заполните `TODO`. Затем соберите образ и запустите контейнер на ВМ. Можно использовать ВМ из ДЗ № 4. Compose необязателен
4. Повторите знакомый обмен через `curl`, теперь на ВМ и для своего инструмента. Сохраните команды и ответы: список инструментов, вызов поиска для существующего клуба и вызов для неизвестного. До остановки контейнера сохраните вывод `docker ps` на ВМ

## 8 баллов: дать ассистенту новую возможность

Придумайте инструмент или расширьте существующий. Назовите вопрос, который **не решает базовый поиск по `club_id`**: например, «Какие клубы встречаются по пятницам?». Реализуйте эту возможность и подключите сервер к ассистенту с поддержкой MCP. Писать второй сервер не нужно

Задайте этот вопрос обычным языком, не называя инструмент. Приложите один реальный диалог: вопрос, имя вызванного инструмента, аргументы, результат вызова и ответ ассистента. Укажите название клиента и настройки без секретов. Один итоговый ответ без записи вызова не показывает, что ассистент воспользовался инструментом

## 10 баллов: оценить работу инструмента в диалоге

Составьте десять запросов для своего инструмента. До запуска запишите ожидаемое поведение, затем проведите десять попыток по [инструкции](assignment/EVAL.md) и заполните [таблицу](assignment/eval.csv). Разберите один результат: что получилось и чем это подтверждается? Оценивается качество проверки, а не доля удачных ответов модели
