# Аудитории клубов: MCP-сервер

## 4 балла: вызвать `ping` через MCP на своём компьютере

Запустите готовый [сервер](server.py) в одном терминале, а из другого отправляйте ему запросы с помощью `curl`. Нужны [Python 3.14](https://www.python.org/downloads/), `curl` и оболочка Bash или Zsh (на Windows подойдёт Bash в WSL). Docker, учебная ВМ и LLM не нужны

**Терминал 1: запустите сервер.** Откройте терминал в корне склонированного репозитория и выполните:

```bash
cd starter
python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --host 127.0.0.1 --port 8000
```

Если команда `python3.14` не найдена, проверьте `python3 --version`: если это 3.14.x, используйте `python3` в команде создания окружения. Дождитесь строки `Uvicorn running on http://127.0.0.1:8000` и оставьте терминал открытым

**Терминал 2: составьте свои запросы.** Сервер принимает JSON-RPC 2.0 через HTTP POST на `http://127.0.0.1:8000/mcp`. Для каждого шага напишите команду `curl`, отправьте её и посмотрите на ответ, прежде чем переходить к следующему

| Шаг | Что выяснить или сделать |
|---|---|
| `initialize` | Представьтесь как клиент и предложите версию протокола `2025-11-25`. Какую версию вернул сервер? |
| `notifications/initialized` | Сообщите, что клиент готов. Здесь нормальный ответ сервера: HTTP 202 без тела |
| `tools/list` | Узнайте, какие инструменты доступны. Найдите `ping` и посмотрите в его `inputSchema`, нужны ли аргументы |
| `tools/call` | Используйте сведения из предыдущего ответа, чтобы вызвать инструмент. Найдите `pong` в результате вызова |

Формат сообщений ищите в разделах [инициализация клиента](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle), [заголовки HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports) и [инструменты](https://modelcontextprotocol.io/specification/2025-11-25/server/tools). В [справочнике curl](https://curl.se/docs/manpage.html) пригодятся `--data` для тела запроса, `--header` для заголовков и `--include`, чтобы увидеть HTTP-статус. Если сервер отклоняет сообщение, сверьте `Content-Type` и `Accept` с документацией по транспорту. После инициализации передавайте согласованную версию в `MCP-Protocol-Version`

**Что сдать на 4:** приложите четыре свои команды и фактические ответы. Для уведомления достаточно HTTP-статуса. По ответу `tools/list` объясните одной фразой, как вы выбрали аргументы для `tools/call`. Сохранив вывод, остановите сервер сочетанием `Ctrl+C` в первом терминале

## 6 баллов: найти аудиторию через MCP на ВМ

Реализуйте в [tools.py](tools.py) инструмент `lookup_club_room(club_id: str)` и зарегистрируйте его в [server.py](server.py) рядом с `ping`. Ищите точное совпадение `club_id` в [schedule.json](schedule.json) и возвращайте строку `room` из найденной записи. Если клуба нет, верните `Клуб не найден` как обычный результат, без исключения. Например, `orbit` и `ORBIT` различаются

**Для локальной отладки** запустите тесты из каталога `starter` в окружении с уровня на 4 балла:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты вызывают функции напрямую и не проверяют регистрацию. Для сдачи проверьте сервер через сеть на учебной ВМ:

1. Скопируйте [Dockerfile.example](Dockerfile.example) в `Dockerfile` и допишите инструкции в местах с `TODO` по [справочнику Dockerfile](https://docs.docker.com/reference/dockerfile/): в образе понадобятся Python, зависимости, код и расписание. На учебной ВМ [соберите образ](https://docs.docker.com/reference/cli/docker/buildx/build/) и [запустите контейнер](https://docs.docker.com/reference/cli/docker/container/run/). Внутри контейнера сервер должен слушать `0.0.0.0:8000`, а порт на ВМ [опубликуйте только на `127.0.0.1`](https://docs.docker.com/engine/network/port-publishing/). [Compose](https://docs.docker.com/compose/) необязателен
2. В терминале **ВМ** повторите шаги из раздела «Терминал 2», используя свои команды с уровня на 4 балла: теперь `127.0.0.1` обозначает саму ВМ. Проверьте, что `tools/list` показывает и `ping`, и `lookup_club_room`. Адаптируйте свой `tools/call` для поиска по `club_id`: для `orbit` ожидается `Б-204`, для `ORBIT` ожидается `Клуб не найден`. Оба вызова должны завершиться без `isError: true`
3. Для отчёта сохраните команды сборки и запуска, вывод `docker ps` до остановки контейнера и фактический обмен `curl`: команды, статус уведомления, список инструментов и оба результата поиска

## 8 и 10 баллов: подключить ассистента и проверить его ответы

Для 8 баллов добавьте свой инструмент или содержательно расширьте поиск, как описано в [условиях задания](../README.md). Укажите, кому он нужен, его параметры и пример результата. Задайте ассистенту обычный вопрос без имени инструмента. Сохраните настройки без секретов и диалог, в котором видны вопрос, выбранный инструмент, аргументы, результат вызова и ответ модели

**Вариант подключения с ноутбука:** оставьте контейнер запущенным на ВМ. На ноутбуке выполните `ssh -N -L 127.0.0.1:18000:127.0.0.1:8000 user@VM_IP`, заменив `user@VM_IP` на адрес для входа по SSH. Пока SSH открыт, порт `18000` ноутбука ведёт на порт `8000` ВМ. Например, в локальном [VS Code с поддержкой MCP](https://code.visualstudio.com/docs/copilot/customization/mcp-servers) выберите `MCP: Add Server` в палитре команд, тип `HTTP` и адрес `http://127.0.0.1:18000/mcp`. В чате в режиме Agent включите инструмент в списке доступных

Облачный MCP-клиент не видит `127.0.0.1` вашего ноутбука: для него это его собственная машина. SSH-подключение не делает сервер публичным. Для облачного клиента нужен разрешённый HTTPS-адрес, доступный из его сети, и поддерживаемая им авторизация. Уточните эти параметры у преподавателя, не публикуйте ключи

Для 10 баллов проведите [проверку на десяти запросах](../assignment/EVAL.md) на том же инструменте и заполните [таблицу результатов](../assignment/eval.csv)
